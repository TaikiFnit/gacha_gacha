第 7 章 — Box と JOIN・集計

所持キャラ一覧 (Box) のような「ユーザー × マスタ」を組み合わせて出す系の API は、 JOIN と GROUP BY と集計関数の出番です。

学習目標

  • INNER / LEFT JOIN の違いを説明できる
  • GROUP BY と集計関数 (COUNT / MIN / MAX / SUM) を使い分けられる
  • 「ユーザーが持っていないキャラ」を抽出する LEFT JOIN パターンを書ける
  • N+1 問題と、それを JOIN 1 本にまとめる発想を理解する

扱うトピック

  1. 「全キャラ一覧 + 自分の所持数」を 1 クエリで返す (LEFT JOIN + COUNT)
  2. レア度別のコンプリート率を出す
  3. 初獲得日 / 最新獲得日を MIN / MAX で取る
  4. サブクエリ vs JOIN — 同じ問題を 2 通りで書く
  5. EXPLAIN ANALYZE で実行計画を読む入り口

参照コード

  • server/app.py の GET /api/box

演習の例

  1. 「未所持キャラ」だけを返す API を増やす
  2. レア度別のコンプ率 (例: SSR 3/3, SR 2/4) を返すクエリ
  3. 所持品ランキング (誰が一番ガチャを引いているか) を SQL で出す
