Chapter 4 骨子のみ

第 4 章 — Python から DB を触る (psycopg 入門)

ここでは ORM を使わず、生 SQL を投げ、生の行を受け取る感覚を養います。 server/db.py がやっていることを行単位で読み解きます。

学習目標

  • psycopg の connect / cursor / execute / fetch* の使い分けが説明できる
  • パラメータプレースホルダ (%s) と SQL インジェクションの関係を説明できる
  • commit / rollback と autocommit の違いを理解する
  • row_factory=dict_row の意味と便利さを言える
  • 本番では ConnectionPool を使う理由を説明できる

扱うトピック

  1. psycopg2 と psycopg(=v3) の違い、なぜ v3 を選んだか
  2. 接続文字列 (DSN) の組み立て方
  3. カーソル経由の SELECT / INSERT / UPDATE
  4. プレースホルダ vs 文字列連結 — インジェクション再現実験
  5. トランザクション境界をどこに置くか
  6. RETURNING を使って採番された id を持ち帰る
  7. 例外: psycopg.errors.UniqueViolation など主要なエラー

参照コード

  • server/db.py — 最小ラッパ
  • server/app.py 各ハンドラの cur.execute(...)

演習の例

  1. プレースホルダを文字列連結に変えて、'; DROP TABLE users;-- を流し込んで何が起きるか観察
  2. 同じ name でユーザーを 2 回登録して UniqueViolation を補足する
  3. autocommit=True にして「コミット忘れたら反映されない」現象を再現
