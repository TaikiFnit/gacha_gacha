Chapter 8 骨子のみ

第 8 章 — セッションと簡易認証

HTTP は ステートレス。「あなたはさっきログインしたあの人」をどう覚えるか? Cookie + セッショントークンの最小実装を読み解きます。

学習目標

  • Cookie と Set-Cookie の流れを書ける
  • HttpOnly / SameSite / Secure の意味を説明できる
  • セッショントークンを「DB に置く」「JWT」の 2 方式の長短が言える
  • CSRF / セッション固定攻撃に対する基本的な防御を知っている

扱うトピック

  1. HTTP がステートレスとはどういうことか
  2. Cookie のヘッダの読み書き (Pythonの http.cookies)
  3. 本実装が採用したセッション (DB に保存) のメリット/デメリット
  4. 有効期限と「掃除」(expires_at < NOW() を消すバッチ)
  5. クロスオリジン Cookie と credentials: "include"

参照コード

  • server/auth.py の create_session / lookup_session
  • server/app.py の SESSION_COOKIE 周辺

演習の例

  1. セッションの TTL を 1 分に短縮 → 1 分後にログインが切れる体験
  2. Cookie を改ざんしてみる (DevTools) → 401 になることを確認
  3. JWT 版に書き換えてみる (sessions テーブル不要にする)
