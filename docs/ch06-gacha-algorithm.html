第 6 章 — 重み付き乱択 (ガチャ抽選アルゴリズム)

ガチャシステムで一番面白い章。「特定の確率で 1 つ選ぶ」 を、Python と SQL の 2 通りの実装で書き比べます。

学習目標

  • 重み合計を分母にした抽選 (累積和 + 二分探索) を自分で実装できる
  • random.choices がやっていることを説明できる
  • SQL だけで抽選する技 (ORDER BY -ln(random())/weight LIMIT 1) の意味を説明できる
  • 大数の法則を使って実装の正しさを検証する方法を知る

扱うトピック

  1. 素朴実装: 重みリストを累積和に変換 → 一様乱数 → 二分探索
  2. random.choices 版 (本実装はこちら)
  3. SQL 版: A-Res 系の重み付きリザバーサンプリング
  4. シード固定 (random.Random(seed)) と再現テスト
  5. 10,000 回引いて、各キャラの出現比が weight 比に近づくか検証
  6. ピックアップ実装 (期間中だけ weight を変える) の考え方

参照コード

  • server/gacha.py
  • server/app.py の POST /api/gacha/pull

演習の例

  1. 累積和 + 二分探索版を自分の手で実装し、本実装と結果が一致することを確認
  2. 10,000 回シミュレーションして、各キャラの出現比をプロット
  3. SSR の weight を 10 倍にしたら出現比はどう変わるか予想 → 検証
