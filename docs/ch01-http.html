Chapter 1 所要時間: 60〜90 分 形式: Colab セルを 1 つずつ追加して動かす

第 1 章 — HTTPサーバーをColabで建てる

この章は Colab に新しいセルを 7 個ぐらい追加して、それぞれにコードを貼って実行する だけで完走できる構成です。 最後のセルの状態が、本物の server/app.py の骨格そのものになります。

📐 進め方

各ステップに 「📒 セル N」 と書かれたコードブロックがあるので、 Colab で + コード を押して新しいセルを増やし、 コードブロック右上の Copy ボタンで丸ごとコピーして貼り付け、 Shift + Enter で実行してください。

各セルの直後に「✅ 期待される出力」 を載せてあるので、 だいたい同じ出力が出れば成功です (タイムスタンプや乱数で多少違うのは正常)。

📝 前提 第 0 章のセル 1 (作業ディレクトリのセットアップ) をすでに実行している前提で進めます。

イントロ — HTTP は「一往復のテキスト」

クライアントが手紙を 1 通送り、サーバーが返事を 1 通返す。 手紙の中身はただのテキスト。 

POST /api/login HTTP/1.1
Host: localhost:8000
Content-Type: application/json
Content-Length: 39

{"name":"alice","password":"secret"}
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
Content-Length: 24

{"user":{"id":1,"name":"alice"}}

これだけです。ヘッダ + 空行 + 本文。 Web の上で動くもの、ぜんぶこの形のテキストの上に積み上がっています。

Step 1 — TCP ソケットだけで HTTP風のテキストを返す

HTTP の前提として、TCP ソケットがバイト列を運んでいます。 Python の socket モジュールを使うと、その層から書けます。

📒 セル A 新しいセルにコピペして実行 (Shift + Enter)。 別スレッドで TCP サーバーを 1 接続だけ受けて、内部から HTTP リクエストを 1 件投げます。 
import socket, threading, urllib.request, time

def step1_serve_once():
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    s.bind(("127.0.0.1", 9000))
    s.listen()
    conn, _ = s.accept()
    raw = conn.recv(4096)
    print("---- received ----")
    print(raw.decode(errors="replace"))
    print("---- end ----")
    body = b"hello, raw tcp\n"
    conn.sendall(b"HTTP/1.1 200 OK\r\n"
                 b"Content-Type: text/plain; charset=utf-8\r\n"
                 b"Content-Length: " + str(len(body)).encode() + b"\r\n"
                 b"\r\n" + body)
    conn.close()
    s.close()

# サーバーを別スレッドで起動 (1 接続受けたら自動で終わる)
t = threading.Thread(target=step1_serve_once, daemon=True)
t.start()
time.sleep(0.1)

# 内部から GET / を投げる
resp = urllib.request.urlopen("http://127.0.0.1:9000/")
print("status:", resp.status)
print("body  :", resp.read().decode())
t.join(timeout=1)
✅ 期待される出力 (例) 
---- received ----
GET / HTTP/1.1
Accept-Encoding: identity
Host: 127.0.0.1:9000
User-Agent: Python-urllib/3.10
Connection: close

---- end ----
status: 200
body  : hello, raw tcp

💡 解説

  • `---- received ----` の中身が、クライアントが送ってきた HTTP リクエストの生テキスト 。普通の英語と改行で書かれている
  • 応答は HTTP/1.1 200 OK\r\n から始め、ヘッダの後に空行 (\r\n\r\n) を入れて本文。これだけで HTTP の仕様を満たす
  • Content-Length は応答ボディのバイト数。これが嘘だとクライアントが固まる

📝 自分でやってみる

  • Content-Type を text/html に変えて、本文を <h1>hello</h1> にしてみる
  • ステータスを 418 (I'm a teapot) にしてみる

Step 2 — `http.server` で最小の Hello GET

Step 1 のように毎回ヘッダを手で書くのは辛い。 Python 標準の http.server に乗り換えます。 BaseHTTPRequestHandler をサブクラス化し、 do_GET をオーバーライドすると GET 全般を捕まえられます。

📒 セル B 
from http.server import BaseHTTPRequestHandler, HTTPServer
import threading, urllib.request, time

class Hello(BaseHTTPRequestHandler):
    def do_GET(self):
        body = b"hello, http\n"
        self.send_response(200)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)
    def log_message(self, fmt, *args): pass  # ログ抑制

server = HTTPServer(("127.0.0.1", 8001), Hello)
threading.Thread(target=server.serve_forever, daemon=True).start()
time.sleep(0.1)

# 何のパスでも同じ応答が返ることを確認
for path in ["/", "/anything", "/api/foo"]:
    r = urllib.request.urlopen("http://127.0.0.1:8001" + path)
    print(f"{path:12s} -> {r.status} {r.read()}")
server.shutdown()
✅ 期待される出力 
/            -> 200 b'hello, http\n'
/anything    -> 200 b'hello, http\n'
/api/foo     -> 200 b'hello, http\n'

💡 解説

  • send_response → send_header → end_headers → wfile.write の順は厳守。 崩すと壊れたレスポンスになる
  • Step 1 で手書きしていた「HTTP/1.1 200 OK...」「ヘッダ後の空行」を、 このメソッド呼び出しが全部やってくれている
  • どのパスでも同じ応答が返るのに気付いた? パスごとに分けるのが Step 3

Step 3 — パスで分岐 + クエリ受け取り

self.path は "/api/echo?msg=hi" のような形で来るので、 urllib.parse.urlparse でパスとクエリに分けます。

📒 セル C 
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse, parse_qs
import json, threading, urllib.request, urllib.error, time

class App(BaseHTTPRequestHandler):
    def do_GET(self):
        url = urlparse(self.path); path = url.path; q = parse_qs(url.query)
        if path == "/":              return self._text(200, "hello, http\n")
        if path == "/api/health":    return self._json(200, {"status": "ok"})
        if path == "/api/echo":      return self._json(200, {"you_said": q.get("msg", [""])[0]})
        return self._json(404, {"error": "Not Found", "path": path})
    def _text(self, s, body):
        b = body.encode(); self.send_response(s)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(b))); self.end_headers(); self.wfile.write(b)
    def _json(self, s, obj):
        b = json.dumps(obj, ensure_ascii=False).encode(); self.send_response(s)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(b))); self.end_headers(); self.wfile.write(b)
    def log_message(self, fmt, *args): pass

server = HTTPServer(("127.0.0.1", 8002), App)
threading.Thread(target=server.serve_forever, daemon=True).start()
time.sleep(0.1)

for path in ["/", "/api/health", "/api/echo?msg=hello%20world", "/missing"]:
    try:
        r = urllib.request.urlopen("http://127.0.0.1:8002" + path)
        print(f"{path:35s} -> {r.status} {r.read().decode()[:80]}")
    except urllib.error.HTTPError as e:
        print(f"{path:35s} -> {e.code} {e.read().decode()[:80]}")
server.shutdown()
✅ 期待される出力 
/                                   -> 200 hello, http
/api/health                         -> 200 {"status": "ok"}
/api/echo?msg=hello%20world         -> 200 {"you_said": "hello world"}
/missing                            -> 404 {"error": "Not Found", "path": "/missing"}

💡 解説

  • parse_qs はクエリ値をリストで返す。 1 個目だけ欲しい場合は q.get("msg", [""])[0]
  • JSON 応答は「json.dumps で文字列化 → .encode() で bytes 化 → wfile.write」
  • _text / _json のような共通ヘルパを用意するとハンドラが短く書ける

📝 自分でやってみる

  • /api/echo で msg が空のとき 400 を返すようにする
  • /api/time を増やして、現在時刻 (datetime.utcnow().isoformat()) を返す

Step 4 — POST で JSON を受け取る

ガチャを引く API は POST します。 本文の長さは Content-Length ヘッダから読み取り、 self.rfile.read(n) でバイト列を取り、JSON にデコードします。

📒 セル D 
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse
import json, threading, urllib.request, urllib.error, time

class App(BaseHTTPRequestHandler):
    def do_POST(self):
        path = urlparse(self.path).path
        n = int(self.headers.get("Content-Length", "0"))
        try:
            body = json.loads(self.rfile.read(n).decode("utf-8")) if n else {}
        except json.JSONDecodeError as e:
            return self._json(400, {"error": f"invalid json: {e}"})
        if path == "/api/echo":
            return self._json(200, {"received": body, "size": n})
        if path == "/api/sum":
            try: a, b = body["a"], body["b"]
            except KeyError: return self._json(400, {"error": "a と b が必要"})
            return self._json(200, {"answer": a + b})
        return self._json(404, {"error": "Not Found"})
    def _json(self, s, obj):
        b = json.dumps(obj, ensure_ascii=False).encode()
        self.send_response(s)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(b))); self.end_headers(); self.wfile.write(b)
    def log_message(self, fmt, *args): pass

server = HTTPServer(("127.0.0.1", 8003), App)
threading.Thread(target=server.serve_forever, daemon=True).start()
time.sleep(0.1)

def post(path, payload):
    req = urllib.request.Request(
        "http://127.0.0.1:8003" + path,
        data=json.dumps(payload).encode(),
        headers={"Content-Type": "application/json"}, method="POST")
    try:
        return urllib.request.urlopen(req).read().decode()
    except urllib.error.HTTPError as e:
        return f"[{e.code}] " + e.read().decode()

print("echo:", post("/api/echo", {"name": "alice", "age": 7}))
print("sum :", post("/api/sum",  {"a": 1, "b": 2}))
print("bad :", post("/api/sum",  {"a": 1}))   # b 欠落で 400
server.shutdown()
✅ 期待される出力 
echo: {"received": {"name": "alice", "age": 7}, "size": 27}
sum : {"answer": 3}
bad : [400] {"error": "a と b が必要"}

💡 解説

  • Content-Length ヘッダを見て、その分だけ rfile.read する。これを忘れると不完全な読み取りになる
  • self.rfile = リクエスト本文を読むためのファイル風オブジェクト / self.wfile = 応答を書くためのファイル風オブジェクト
  • 本文はバイト列。encode()/decode() を必ず通す

Step 5 — ルーター辞書でデータ駆動に

ハンドラが増えてくると do_GET 内の if/elif の山になります。 (method, path) → handler の辞書に置き換えて、 ハンドラ追加はデコレータでやる形にしましょう。これがフレームワークの中身です。

📒 セル E 
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse
import json, threading, urllib.request, urllib.error, time

ROUTES = {}

def route(method, path):
    def deco(fn):
        ROUTES[(method.upper(), path)] = fn
        return fn
    return deco

@route("GET", "/api/health")
def health(h):
    h._json(200, {"status": "ok"})

@route("POST", "/api/echo")
def echo(h):
    body = h._read_json()
    h._json(200, {"received": body, "size": len(json.dumps(body).encode())})

@route("POST", "/api/sum")
def add(h):
    body = h._read_json()
    h._json(200, {"answer": body["a"] + body["b"]})

class App(BaseHTTPRequestHandler):
    def do_GET(self):    self._dispatch("GET")
    def do_POST(self):   self._dispatch("POST")
    def _dispatch(self, method):
        path = urlparse(self.path).path
        handler = ROUTES.get((method, path))
        if handler is None:
            return self._json(404, {"error": "Not Found",
                                    "available": [f"{m} {p}" for (m, p) in sorted(ROUTES)]})
        handler(self)
    def _read_json(self):
        n = int(self.headers.get("Content-Length", "0"))
        raw = self.rfile.read(n) if n else b""
        return json.loads(raw.decode("utf-8")) if raw else {}
    def _json(self, s, obj):
        b = json.dumps(obj, ensure_ascii=False).encode()
        self.send_response(s)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(b))); self.end_headers(); self.wfile.write(b)
    def log_message(self, fmt, *args): pass

server = HTTPServer(("127.0.0.1", 8004), App)
threading.Thread(target=server.serve_forever, daemon=True).start()
time.sleep(0.1)

# 既存ルートと、無いルートを叩いてみる
print("health:", urllib.request.urlopen("http://127.0.0.1:8004/api/health").read().decode())

req = urllib.request.Request("http://127.0.0.1:8004/api/sum",
        data=json.dumps({"a": 10, "b": 32}).encode(),
        headers={"Content-Type": "application/json"}, method="POST")
print("sum   :", urllib.request.urlopen(req).read().decode())

try:
    urllib.request.urlopen("http://127.0.0.1:8004/api/missing")
except urllib.error.HTTPError as e:
    print("404   :", e.read().decode())
server.shutdown()
✅ 期待される出力 
health: {"status": "ok"}
sum   : {"answer": 42}
404   : {"error": "Not Found", "available": ["GET /api/health", "POST /api/echo", "POST /api/sum"]}

💡 解説

  • @route("GET", "/api/health") で関数を ROUTES 辞書に登録
  • _dispatch は (method, path) をキーに辞書を引くだけ。 if/elif が消えた
  • このパターンは Flask, FastAPI, Express など、あらゆる Web フレームワークの中身

Step 6 — 例外を JSON エラーに変換する

ハンドラ内で raise bad_request("a と b は数値で") と書くと、 自動的に 400 + {"error": "..."} が返る形を作ります。 予期しない例外は traceback を出して 500 を返す。 これで本物の server/app.py と同じ骨格に到達します。

📒 セル F 
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse
import json, threading, traceback, urllib.request, urllib.error, time

class AppError(Exception):
    def __init__(self, status, message):
        super().__init__(message)
        self.status, self.message = status, message

def bad_request(msg):  return AppError(400, msg)
def not_found(msg="Not Found"): return AppError(404, msg)

ROUTES = {}
def route(method, path):
    def deco(fn):
        ROUTES[(method.upper(), path)] = fn
        return fn
    return deco

@route("GET", "/api/health")
def health(h):
    h._json(200, {"status": "ok"})

@route("POST", "/api/sum")
def add(h):
    body = h._read_json()
    if "a" not in body or "b" not in body:
        raise bad_request("a と b が必要")
    a, b = body["a"], body["b"]
    if not isinstance(a, (int, float)) or not isinstance(b, (int, float)):
        raise bad_request("a と b は数値で")
    h._json(200, {"answer": a + b})

class App(BaseHTTPRequestHandler):
    def do_GET(self):  self._dispatch("GET")
    def do_POST(self): self._dispatch("POST")
    def _dispatch(self, method):
        path = urlparse(self.path).path
        handler = ROUTES.get((method, path))
        if handler is None:
            return self._json(404, {"error": "Not Found", "path": path})
        try:
            handler(self)
        except AppError as e:
            self._json(e.status, {"error": e.message})
        except Exception as e:
            traceback.print_exc()
            self._json(500, {"error": "internal server error", "detail": str(e)})
    def _read_json(self):
        n = int(self.headers.get("Content-Length", "0"))
        raw = self.rfile.read(n) if n else b""
        try:
            return json.loads(raw.decode("utf-8")) if raw else {}
        except json.JSONDecodeError as e:
            raise bad_request(f"invalid json: {e}")
    def _json(self, s, obj):
        b = json.dumps(obj, ensure_ascii=False).encode()
        self.send_response(s)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(b))); self.end_headers(); self.wfile.write(b)
    def log_message(self, fmt, *args): pass

server = HTTPServer(("127.0.0.1", 8005), App)
threading.Thread(target=server.serve_forever, daemon=True).start()
time.sleep(0.1)

def hit(method, path, payload=None):
    req = urllib.request.Request("http://127.0.0.1:8005" + path,
            data=json.dumps(payload).encode() if payload is not None else None,
            headers={"Content-Type": "application/json"} if payload is not None else {},
            method=method)
    try:
        r = urllib.request.urlopen(req)
        return r.status, r.read().decode()
    except urllib.error.HTTPError as e:
        return e.code, e.read().decode()

print("健康  :", hit("GET",  "/api/health"))
print("足し算 :", hit("POST", "/api/sum", {"a": 1, "b": 2}))
print("型違反 :", hit("POST", "/api/sum", {"a": "x", "b": 2}))
print("欠損  :", hit("POST", "/api/sum", {"a": 1}))
server.shutdown()
✅ 期待される出力 
健康  : (200, '{"status": "ok"}')
足し算 : (200, '{"answer": 3}')
型違反 : (400, '{"error": "a と b は数値で"}')
欠損  : (400, '{"error": "a と b が必要"}')

💡 解説

  • AppError は「ステータス付きの例外」。 ビジネスロジック側で raise bad_request("...") と書くだけで、 ディスパッチ側がそれを 400 の JSON に変えてくれる
  • 予期せぬ例外は traceback.print_exc() で サーバーログに出して、 クライアントには 500 を返す
  • この形にしておくと、ハンドラの中身がドメインロジックだけに集中できる (バリデーションや権限チェックは raise 1 行で表現)
