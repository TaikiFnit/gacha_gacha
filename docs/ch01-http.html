第 1 章 — HTTPサーバーを段階的に組み立てる

この章で書く HTTP サーバ myserver.py は、 これから先の章でもずっと触り続けるあなた自身のコードになります。 ステップ 1 で最小サーバを動かし、 以降のステップでは同じファイルを書き足し / 書き換え ながら 機能を足していきます。 第 3 章以降は、 ここで組み立てたサーバをそのまま運んで ガチャ API へ拡張していきます。

📐 進め方

各ステップは:

  1. 📒 myserver.py をコードブロックの内容で書き換え (もしくは新規作成) → 保存
  2. PowerShell ターミナル A で python myserver.py を起動
  3. PowerShell ターミナル B で curl もしくは Bruno でリクエストを投げる

各ステップが終わるたびに 動くサーバが手元にある 状態になります。 最後のステップ 6 が、 そのまま「あなたの HTTP サーバ完成版」 になります。

📝 前提 第 0 章で Python / Bruno のインストール、 PowerShell の動作確認が済んでいる前提で進めます。 作業フォルダは Ch.0 で作った $HOME\gacha_workspace を想定。

1.1 HTTP は「ヘッダ + 空行 + 本文」 のテキスト

クライアントが手紙を 1 通送り、 サーバーが返事を 1 通返す。 手紙の中身はただのテキストです。 

POST /api/login HTTP/1.1
Host: localhost:8000
Content-Type: application/json
Content-Length: 39

{"name":"alice","password":"secret"}
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
Content-Length: 32

{"user":{"id":1,"name":"alice"}}

Web の上で動くもの全て、 結局はこの形のテキストの上に積み上がっています。

📚 コラム: URL の構造 / localhost / ポート番号

HTTP リクエストの 1 行目には URL のパス部分 が入っていました。 では URL 全体は どんな構造をしているのか? 

https://example.com:443/api/users?id=1#top
└┬─┘   └─────┬─────┘└┬┘└────┬────┘└─┬─┘└┬┘
スキーム  ホスト    ポート  パス    クエリ フラグメント
  • スキーム: http or https (暗号化付き)
  • ホスト: 通信相手のマシン名。 ドメイン名は DNS で IP アドレスに変換される
  • ポート番号: 同じマシンに複数のサーバが立っているとき、 番号で識別する (= ビルの号室番号みたいなもの)。 0〜65535 の整数。 1024 未満は OS 予約 (HTTP=80、 HTTPS=443、 SSH=22 等)。 自作サーバは 1024 以上を使う (例: 8000、 5500)
  • パス: サーバ上のリソース位置。 これが本章で見ている self.path
  • クエリ: ?key=value&k2=v2 形式の追加パラメータ。 ステップ 3 で parse_qs で分解する
  • フラグメント: ページ内アンカー。 サーバには送られず、 ブラウザだけが見る

localhost は 「自分のマシン自身」 を指す特別な名前で、 IP アドレスでは 127.0.0.1 (IPv4) または ::1 (IPv6)。 他の人からは見えず、 自分のマシン内だけで完結する通信に使います。 開発中の通常の宛先。

本章のサーバは http://127.0.0.1:8000 (= http://localhost:8000) で待ち受けますが、 これは「自分のマシンの 8000 番ポートに、 暗号化なしの HTTP で繋ぐ」 という意味。

📚 コラム: HTTP ステータスコード — 数字 3 桁の意味

この章でも何度も出てくる self.send_response(200) の 200。 この 3 桁の数字を HTTP ステータスコードと呼び、 「サーバがクライアントに何を伝えたいか」 を ザックリ表します。 1 桁目で大別すると:

範囲意味代表例
1xx情報 (めったに見ない)100 Continue
2xx成功 200 OK (普通の成功)、 201 Created (作った)、 204 No Content (返事だけ、 中身なし)
3xxリダイレクト301 Moved Permanently、 302 Found、 304 Not Modified
4xxクライアントが悪い 400 Bad Request (リクエスト不正)、 401 Unauthorized (未ログイン)、 403 Forbidden (権限なし)、 404 Not Found (パスが無い)、 418 I'm a teapot (お茶目)
5xxサーバが悪い 500 Internal Server Error (バグ)、 502 Bad Gateway、 503 Service Unavailable

覚え方: 4xx は「あなたのリクエストの問題」、 5xx は「サーバ側のバグ」。 ログを見たとき 5xx が出ていたら自分のコードを疑い、 4xx ならクライアント (= フロントや REST クライアント) の送り方を疑う、 というのが基本の切り分け。

本教材で頻出するのは: 200 / 400 / 401 / 404 / 500 の 5 つです。 それ以外は出てきたときに調べれば十分。

📚 ヒント: ブラウザの DevTools (開発者ツール) の Network タブ

ブラウザは すべての HTTP 往復を全部記録 していて、 開発者ツールから覗けます。 本教材では Ch.4 以降で重要になります。

  • 開き方: ブラウザのページ上で 右クリック → 「検証」 (Inspect) → 上タブの「Network」 (Chrome / Edge) または「ネットワーク」 (Firefox)
  • キーボードショートカット: Windows は Ctrl+Shift+I
  • ページを再読み込みすると、 そのページが投げた HTTP リクエストが全部一覧で出る
  • 1 行クリック → リクエストヘッダ、 レスポンスヘッダ、 ステータスコード、 ボディ、 所要時間 が見える

1.3 ステップ 1 — TCP socket で HTTP 風応答

まずは Python 標準の socket モジュールだけで、 HTTP 風のテキストを 手書きして返すサーバを作ってみます。 行数で言うと 20 行ちょっと。 これで「HTTP は単なるテキスト」 を体感できます。

📝 myserver.py — TCP ソケットで HTTP 風応答 
# myserver.py — ステップ 1: TCP ソケットで HTTP 風応答
import socket

def main():
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    # 同じポートで再起動できるようにする小ワザ
    sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    sock.bind(("127.0.0.1", 8000))
    sock.listen()
    print("listening on http://127.0.0.1:8000  (Ctrl+C で終了)")

    while True:
        conn, addr = sock.accept()
        data = conn.recv(4096)
        print("---- received ----")
        print(data.decode(errors="replace"))
        print("---- end -----")

        body = b"hello, raw tcp\n"
        response = (
            b"HTTP/1.1 200 OK\r\n"
            b"Content-Type: text/plain; charset=utf-8\r\n"
            b"Content-Length: " + str(len(body)).encode() + b"\r\n"
            b"\r\n"
            + body
        )
        conn.sendall(response)
        conn.close()

if __name__ == "__main__":
    main()

# → listening on http://127.0.0.1:8000  (Ctrl+C で終了)

# ターミナル B (別の PowerShell ウィンドウ)

✅ 期待される出力 
# ターミナル B 側 (curl の応答):
hello, raw tcp

# ターミナル A 側に、 curl が送ってきたリクエスト全文が表示される:
---- received ----
GET / HTTP/1.1
Host: 127.0.0.1:8000
User-Agent: curl/8.x.x
Accept: */*

---- end -----

💡 解説

  • HTTP は本当にテキスト: ターミナル A 側に出ているのは、 ブラウザや curl が 送ってきた 生のテキスト。 これを Python が受け取って、 同じくテキストの形式で返事を返している
  • 改行は \r\n: HTTP の仕様では行末は CRLF (キャリッジリターン + ラインフィード)。 Python ソースコード上は \r\n と書く
  • ヘッダと本文は空行で区切る: b"\r\n" だけの行が「ヘッダ終わり、 ここから本文」 の合図

📝 自分でちょっと変えてみる

  • body を b"\xe3\x81\x93\xe3\x82\x93\xe3\x81\xab\xe3\x81\xa1\xe3\x81\xaf\n" (=「こんにちは」 の UTF-8) にしてみる。 curl の出力で日本語が出る?
  • HTTP/1.1 200 OK を HTTP/1.1 418 I'm a teapot にしてみる。 curl -v で見るとステータス行が変わっている

この実装で困るのは、 HTTP リクエストのパースを完全に自分でやる必要があること。 ヘッダの分解、 メソッド判定、 パス解釈、 本文の読み取りなど、 全部書くのは大変です。 次のステップで Python 標準の http.server に乗り換え、 そういう面倒を肩代わりしてもらいます。

1.4 ステップ 2 — http.server に乗り換え

Python 標準の http.server モジュールにある BaseHTTPRequestHandler を継承し、 do_GET をオーバーライドすれば、 メソッドとパスのパースは全部やってくれます。 ステップ 1 と同じ「Hello」 を、 たった半分以下の行数で書き直します。

📝 myserver.py — http.server に乗り換え 
# myserver.py — ステップ 2: http.server で最小の Hello サーバ
from http.server import BaseHTTPRequestHandler, HTTPServer

class App(BaseHTTPRequestHandler):
    def do_GET(self):
        body = b"hello, http\n"
        self.send_response(200)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

def main():
    addr = ("127.0.0.1", 8000)
    print(f"listening on http://{addr[0]}:{addr[1]}  (Ctrl+C で終了)")
    HTTPServer(addr, App).serve_forever()

if __name__ == "__main__":
    main()
▶️ 動かす 
# ターミナル A: 前のサーバが動いていたら Ctrl+C で止めてから
python myserver.py

# ターミナル B
curl http://127.0.0.1:8000/
curl http://127.0.0.1:8000/anything

# ブラウザで http://127.0.0.1:8000/ を開いても OK
✅ 期待される出力 
hello, http

💡 解説

  • BaseHTTPRequestHandler をサブクラス化し、 do_GET をオーバーライドすれば GET 全般を受けられる (POST なら do_POST)
  • 呼び出し順は send_response → send_header → end_headers → wfile.write を必ず守る。 これがイントロで見た「ヘッダ + 空行 + 本文」 の組み立て
  • 本文は bytes (b"...") なので、 文字列を送るときは .encode() が必要
  • サーバ起動中はターミナル A にアクセスログが出る (例: 127.0.0.1 - - [...] "GET / HTTP/1.1" 200 -)

📝 自分でちょっと変えてみる

  • Content-Type を text/html にして、 body を b"<h1>hello</h1>" に。 ブラウザで開くと太字の見出しになる
  • send_response(200) を 404 にして、 curl -i で見るとステータス行が変わっている

1.5 ステップ 3 — パスごとに違う応答 (ルーティング)

self.path を見て、 / なのか /api/health なのかで応答を変える。 ルーティングの素朴版です。 同時に、 文字列を返すヘルパ _text と JSON を返すヘルパ _json も用意して、 do_GET 本体をスッキリさせます。

📝 myserver.py — パス分岐 + ヘルパ 
# myserver.py — ステップ 3: パスごとに分岐 + JSON 返却
import json
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse, parse_qs

class App(BaseHTTPRequestHandler):
    def do_GET(self):
        url = urlparse(self.path)
        path = url.path
        query = parse_qs(url.query)

        if path == "/":
            return self._text(200, "hello, http\n")
        if path == "/api/health":
            return self._json(200, {"status": "ok"})
        if path == "/api/echo":
            msg = query.get("msg", [""])[0]
            return self._json(200, {"you_said": msg})
        return self._json(404, {"error": "Not Found", "path": path})

    # ---- helpers --------------------------------------------------------
    def _text(self, status, s):
        b = s.encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

    def _json(self, status, obj):
        b = json.dumps(obj, ensure_ascii=False).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

def main():
    addr = ("127.0.0.1", 8000)
    print(f"listening on http://{addr[0]}:{addr[1]}  (Ctrl+C で終了)")
    HTTPServer(addr, App).serve_forever()

if __name__ == "__main__":
    main()

  • _text / _json のような共通ヘルパを切り出すと、 ハンドラの中身が「ロジック」 だけになって読みやすい
  • ステップ 1〜2 でやったヘッダ書きの儀式が、 _json 一行に圧縮されている

  • /api/echo で msg が空のとき 400 を返す
📚 コラム: そもそも JSON とは?

JSON (JavaScript Object Notation) は、 構造化データを 「人間が読めるテキスト」として表現する形式です。 由来は 2000 年代前半に Douglas Crockford が広めたもので、 JavaScript のオブジェクトリテラル構文を抜き出して 言語を問わず使える書式に整えた、 という出自。 現在は ECMA-404 / RFC 8259 として標準化されています。

仕様の核 (これだけ覚えておけば 99% 困らない)

JSON で表せる値は 6 種類 しかありません:

  • "文字列" (二重引用符必須。 シングルクォートは不可)
  • 123, 3.14, -5 等の数値 (整数と実数の区別なし。 NaN / Infinity は不可)
  • true / false
  • null
  • [ 値, 値, ... ] = 配列
  • { "キー": 値, ... } = オブジェクト (キーは必ず文字列)

JSON でハマりやすい所

  • シングルクォート不可: {'a': 1} は不正な JSON。 必ず {"a": 1}
  • 末尾カンマ不可: [1, 2, 3,] は不正
  • コメント不可: // hello は不正
  • キーは必ず文字列: {1: "a"} は不正 ({"1": "a"} なら OK)
  • 日時型は無い: ISO 8601 文字列 ("2026-04-27T06:30:00Z") で渡すのが慣例

Python での扱いは標準ライブラリ json で: 

import json
json.dumps({"a": 1, "b": [True, None, "hi"]})  # → '{"a": 1, "b": [true, null, "hi"]}'
json.loads('{"a": 1}')                          # → {"a": 1}  (Python の dict)

Python の True / None ↔ JSON の true / null の対応は json モジュールが自動でやってくれます。

1.6 ステップ 4 — POST で JSON を受け取る + Bruno を使う

ガチャを引く API は POST します (= 副作用がある操作)。 do_POST を増やして、 本文の JSON を読み取って返事を作ります。

💻 Bruno を初めて使う

ここまでは curl で叩いてきました。 GET だけなら curl で十分ですが、 POST + JSON ボディを毎回打つのは面倒です。 Ch.0 で入れた Bruno を使います。

  1. Bruno を起動 → 上のメニューから Collection → Create Collection
  2. 名前: gacha_local、 場所: $HOME\gacha_workspace\bruno にしておく
  3. 左ペインで右クリック → New Request → 名前: POST sum
  4. メソッド: POST、 URL: http://127.0.0.1:8000/api/sum
  5. 下の Body タブ → JSON を選択 → {"a": 1, "b": 2} を入力
  6. 右上の Send ボタン

収集したリクエストは $HOME\gacha_workspace\bruno\ 配下に .bru というテキストファイルとして保存されます。 git にコミットしてチームで共有することもできます。

📝 myserver.py — POST + JSON 受信 
# myserver.py — ステップ 4: POST で JSON を受け取る
import json
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse, parse_qs

class App(BaseHTTPRequestHandler):
    def do_GET(self):
        url = urlparse(self.path)
        path = url.path
        query = parse_qs(url.query)
        if path == "/":              return self._text(200, "hello, http\n")
        if path == "/api/health":    return self._json(200, {"status": "ok"})
        if path == "/api/echo":      return self._json(200, {"you_said": query.get("msg", [""])[0]})
        return self._json(404, {"error": "Not Found", "path": path})

    def do_POST(self):
        path = urlparse(self.path).path
        body = self._read_json()
        if path == "/api/echo":
            return self._json(200, {"received": body})
        if path == "/api/sum":
            if "a" not in body or "b" not in body:
                return self._json(400, {"error": "a と b が必要"})
            return self._json(200, {"answer": body["a"] + body["b"]})
        return self._json(404, {"error": "Not Found", "path": path})

    # ---- helpers --------------------------------------------------------
    def _read_json(self):
        n = int(self.headers.get("Content-Length", "0"))
        raw = self.rfile.read(n) if n else b""
        try:
            return json.loads(raw.decode("utf-8")) if raw else {}
        except json.JSONDecodeError:
            return {}

    def _text(self, status, s):
        b = s.encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

    def _json(self, status, obj):
        b = json.dumps(obj, ensure_ascii=False).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

def main():
    addr = ("127.0.0.1", 8000)
    print(f"listening on http://{addr[0]}:{addr[1]}  (Ctrl+C で終了)")
    HTTPServer(addr, App).serve_forever()

if __name__ == "__main__":
    main()

  • 大事な観察: ステップ 3 で動いていた GET は今もそのまま動く。 機能を足しても以前の機能が壊れていないか、 毎回確かめると安心

📚 コラム: 「デコレータ」 ってなに?

次のステップで @route("GET", "/api/health") という見慣れない記法が出てきます。 これを使う前に、 デコレータ という概念をおさえます。

① Python のデコレータ — 「関数を関数に変換する」 構文

Python では関数も値です。 関数を引数に取って別の関数を返す関数が書けます:

def loud(fn):
    """fn を呼び出すたびに「呼ばれた!」 と叫ぶ新しい関数を作って返す。"""
    def wrapped(*args, **kwargs):
        print(f"呼ばれた! ({fn.__name__})")
        return fn(*args, **kwargs)
    return wrapped

def hello(name):
    return f"hi, {name}"

# 1) 普通に書くと:
hello = loud(hello)      # ← hello を loud で「装飾」 して再代入
hello("alice")
# 呼ばれた! (hello)
# → 'hi, alice'

この「関数 = 関数を装飾するもの(関数)」 を毎回書くのは面倒なので、 Python は専用の構文糖衣を用意しました。 それが @: 

@loud                    # ← この一行が「hello = loud(hello)」 と等価
def hello(name):
    return f"hi, {name}"

つまり @デコレータ は 「直後の関数を、 そのデコレータに通したものに置き換える」 ためのショートカット。 関数定義の真上に書くのが約束です。

② パラメータを取るデコレータ

次のステップで使う @route("GET", "/api/health") のようにカッコ付きの デコレータは、 もう 1 段ネストします: 

def route(method, path):           # ← 引数を受け取って
    def deco(fn):                  # ← 「関数を装飾する関数」 を返す
        ROUTES[(method, path)] = fn
        return fn                  # ← 装飾と言いつつ、 中身はそのまま返す
    return deco

@route("GET", "/api/health")
def health(h):
    h._json(200, {"status": "ok"})

ここで起きているのは「関数 health を、 ROUTES 辞書に登録するついでに、 中身は変えずに返す」。 典型例は Flask の @app.route(...)、 FastAPI の @app.get(...)、 Django の @login_required、 pytest の @pytest.fixture など。

1.7 ステップ 5 — リファクタ: ルーター辞書 + デコレータ

ハンドラが増えると do_GET / do_POST 内の if/elif の山になります。 (method, path) → handler の辞書でディスパッチする形に書き換えます。 機能は変わらないので、 ステップ 4 のテストがそのままパスすれば成功です。

📝 myserver.py — ルーター辞書 + デコレータ 
# myserver.py — ステップ 5: ルーター辞書 + @route デコレータ
import json
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse, parse_qs

# (method, path) -> handler 関数 の辞書
ROUTES = {}

def route(method, path):
    """関数をルートとして ROUTES に登録するデコレータ。"""
    def deco(fn):
        ROUTES[(method.upper(), path)] = fn
        return fn
    return deco

# ---- ルートの定義 -----------------------------------------------------------
@route("GET", "/")
def root(h):
    h._text(200, "hello, http\n")

@route("GET", "/api/health")
def health(h):
    h._json(200, {"status": "ok"})

@route("GET", "/api/echo")
def echo_get(h):
    msg = parse_qs(urlparse(h.path).query).get("msg", [""])[0]
    h._json(200, {"you_said": msg})

@route("POST", "/api/echo")
def echo_post(h):
    h._json(200, {"received": h._read_json()})

@route("POST", "/api/sum")
def add(h):
    body = h._read_json()
    if "a" not in body or "b" not in body:
        return h._json(400, {"error": "a と b が必要"})
    h._json(200, {"answer": body["a"] + body["b"]})


# ---- ディスパッチ: メソッド + パスで ROUTES を引いて呼ぶだけ ---------------
class App(BaseHTTPRequestHandler):
    def do_GET(self):  self._dispatch("GET")
    def do_POST(self): self._dispatch("POST")

    def _dispatch(self, method):
        path = urlparse(self.path).path
        handler = ROUTES.get((method, path))
        if handler is None:
            return self._json(404, {
                "error": "Not Found", "path": path,
                "available": [f"{m} {p}" for (m, p) in sorted(ROUTES)],
            })
        handler(self)

    def _read_json(self):
        n = int(self.headers.get("Content-Length", "0"))
        raw = self.rfile.read(n) if n else b""
        try:
            return json.loads(raw.decode("utf-8")) if raw else {}
        except json.JSONDecodeError:
            return {}

    def _text(self, status, s):
        b = s.encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

    def _json(self, status, obj):
        b = json.dumps(obj, ensure_ascii=False).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

def main():
    addr = ("127.0.0.1", 8000)
    print(f"listening on http://{addr[0]}:{addr[1]}  (Ctrl+C で終了)")
    print("ルート一覧:")
    for (m, p) in sorted(ROUTES):
        print(f"  {m:5s} {p}")
    HTTPServer(addr, App).serve_forever()

if __name__ == "__main__":
    main()
✅ 期待される出力 (= ステップ 4 までの全機能が引き続き動く)

listening on http://127.0.0.1:8000  (Ctrl+C で終了)
ルート一覧:
  GET   /
  GET   /api/echo
  GET   /api/health

{"error": "Not Found", "path": "/missing",
 "available": ["GET /", "GET /api/echo", "GET /api/health",
               "POST /api/echo", "POST /api/sum"]}

💡 解説

  • ハンドラの登録は @route("GET", "/api/health") というデコレータ。 関数を ROUTES 辞書に詰めてくれる
  • _dispatch は単に ROUTES.get((method, path)) でハンドラを引いて呼ぶだけ。 if/elif の山が消えた
  • 機能不変のリファクタは「テストでガードする」 のが鉄則。 Bruno の Collection に Send をひと通り走らせて、 全部以前と同じ結果なら安心して進められる
  • このパターンは Flask, FastAPI, Express など あらゆる Web フレームワークの中身そのもの

1.8 ステップ 6 — 例外を JSON エラーに変える

ハンドラ内で raise bad_request("a と b は数値で") と書くだけで、 自動的に 400 + {"error": "..."} が返るようにします。 予期しない例外は traceback を出して 500。 これであなたのサーバが完成します。

📝 myserver.py — 例外ハンドリングつき完成版 
# myserver.py — ステップ 6 (完成版): 例外を JSON エラーに変える
import json
import traceback
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse, parse_qs

ROUTES = {}

def route(method, path):
    def deco(fn):
        ROUTES[(method.upper(), path)] = fn
        return fn
    return deco

class AppError(Exception):
    """ステータス付きの例外。 ハンドラから raise すると JSON エラーで返る。"""
    def __init__(self, status, message):
        super().__init__(message)
        self.status, self.message = status, message

def bad_request(msg): return AppError(400, msg)
def unauthorized(msg="ログインが必要です"): return AppError(401, msg)
def not_found(msg="見つかりません"): return AppError(404, msg)


# ---- ルートの定義 -----------------------------------------------------------
@route("GET", "/")
def root(h):
    h._text(200, "hello, http\n")

@route("GET", "/api/health")
def health(h):
    h._json(200, {"status": "ok"})

@route("GET", "/api/echo")
def echo_get(h):
    msg = parse_qs(urlparse(h.path).query).get("msg", [""])[0]
    h._json(200, {"you_said": msg})

@route("POST", "/api/echo")
def echo_post(h):
    h._json(200, {"received": h._read_json()})

@route("POST", "/api/sum")
def add(h):
    body = h._read_json()
    if "a" not in body or "b" not in body:
        raise bad_request("a と b が必要")
    a, b = body["a"], body["b"]
    if not isinstance(a, (int, float)) or not isinstance(b, (int, float)):
        raise bad_request("a と b は数値で")
    h._json(200, {"answer": a + b})


# ---- ディスパッチ ----------------------------------------------------------
class App(BaseHTTPRequestHandler):
    def do_GET(self):  self._dispatch("GET")
    def do_POST(self): self._dispatch("POST")

    def _dispatch(self, method):
        path = urlparse(self.path).path
        handler = ROUTES.get((method, path))
        if handler is None:
            return self._json(404, {"error": "Not Found", "path": path})
        try:
            handler(self)
        except AppError as e:
            self._json(e.status, {"error": e.message})
        except Exception as e:
            traceback.print_exc()       # サーバログには全文出す
            self._json(500, {"error": "internal server error", "detail": str(e)})

    def _read_json(self):
        n = int(self.headers.get("Content-Length", "0"))
        raw = self.rfile.read(n) if n else b""
        try:
            return json.loads(raw.decode("utf-8")) if raw else {}
        except json.JSONDecodeError as e:
            raise bad_request(f"invalid json: {e}")

    def _text(self, status, s):
        b = s.encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

    def _json(self, status, obj):
        b = json.dumps(obj, ensure_ascii=False).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

def main():
    addr = ("127.0.0.1", 8000)
    print(f"listening on http://{addr[0]}:{addr[1]}  (Ctrl+C で終了)")
    print("ルート一覧:")
    for (m, p) in sorted(ROUTES):
        print(f"  {m:5s} {p}")
    HTTPServer(addr, App).serve_forever()

if __name__ == "__main__":
    main()
▶️ Bruno で叩いてみる

Bruno の Collection に以下を作って Send:

  • POST /api/sum (正常): body {"a": 10, "b": 32} → 200, {"answer": 42}
  • POST /api/sum (欠損): body {"a": 10} → 400, {"error": "a と b が必要"}
  • POST /api/sum (型違反): body {"a": "x", "b": 32} → 400, {"error": "a と b は数値で"}
  • POST /api/sum (壊れた JSON): body タブの直入力で {a:1} (= 不正) → 400, {"error": "invalid json: ..."}

💡 解説

  • AppError は「ステータス付きの例外」 = 業務ロジック側で raise bad_request("...") と書くと、 ディスパッチ側が 400 の JSON に変換
  • 予期しない例外は traceback.print_exc() でサーバログに流し、 クライアントには 500 を返す。 ユーザーには内部詳細を見せない
  • この形にしておくと、 ハンドラの中身が「ドメインロジックだけ」 になる (バリデーションや権限チェックは raise 1 行で表現)
