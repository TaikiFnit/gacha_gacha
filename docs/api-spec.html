📘 gacha_gacha API 仕様書

フロントエンド (web/index.html) が叩く API の一覧と、 期待される request / response の形式です。 サーバを実装するときは、これと同じ形を返せばフロントが正しく動きます。 フォーマットが少しでも崩れた場合は、フロントの「🔍 デバッグコンソール」 が 生のレスポンスを見せてくれるので、ここを見比べてどこが違うか直していきます。

全体像

共通ルール

  • すべて JSON。 リクエスト本文は Content-Type: application/json
  • 認証は Cookie (gg_session)。 POST /api/login または POST /api/register 成功時に Set-Cookie で発行
  • エラー時は {"error": "メッセージ"} という共通形式
  • CORS はフロントの origin (localhost:5500 等) を許可済み

ステータスコード

  • 200 正常
  • 400 入力エラー (バリデーション NG / 残コイン不足など)
  • 401 ログインしていない / セッション切れ
  • 404 パスが存在しない / 指定 ID が無い
  • 500 サーバ側でバグった (traceback がサーバログに出る)

エンドポイント一覧

POST /api/register 認証不要

新規ユーザー登録。 成功すると Cookie でセッションが始まる。

リクエスト

{
  "name": "alice",
  "password": "secret123",
  "display_name": "アリス"
}

レスポンス (200)

{
  "user": {
    "id": 1,
    "name": "alice",
    "display_name": "アリス",
    "coins": 1000
  }
}

エラー

条件ステータス本文
name が短い/長い (3〜32文字でない)400{"error": "name は 3〜32 文字"}
password が 6 文字未満400{"error": "password は 6 文字以上"}
その name が既に登録済み400{"error": "その name は既に使われています"}

POST /api/login 認証不要

既存ユーザーでログイン。 成功すると Cookie 発行。

リクエスト

{ "name": "alice", "password": "secret123" }

レスポンス (200)

{
  "user": { "id": 1, "name": "alice", "display_name": "アリス", "coins": 1000 }
}

エラー

条件ステータス本文
name もしくは password が違う401{"error": "name か password が違います"}

POST /api/logout 要認証

セッション破棄。

レスポンス (200)

{ "ok": true }

GET /api/me 要認証

自分の情報。 起動時に呼んでログイン状態か確認する。

レスポンス (200)

{
  "user": { "id": 1, "name": "alice", "display_name": "アリス", "coins": 900 }
}

エラー

条件ステータス本文
Cookie 無し / 期限切れ / 改ざん401{"error": "ログインが必要です"}

GET /api/gacha/list 認証不要

利用可能なガチャ筐体の一覧。

レスポンス (200)

{
  "gachas": [
    { "id": 1, "name": "通常ガチャ",      "price": 100, "pool_size": 12, "total_weight": 505 },
    { "id": 2, "name": "プレミアムガチャ", "price": 300, "pool_size":  7, "total_weight": 175 }
  ]
}

POST /api/gacha/pull 要認証

指定ガチャを 1 回引く。 コインを消費し、結果を返す。

リクエスト

{ "gacha_id": 1 }

レスポンス (200)

{
  "gacha":    { "id": 1, "name": "通常ガチャ", "price": 100 },
  "character": {
    "id": 10, "name": "ドラゴン", "rarity": 5, "emoji": "🐉"
  },
  "obtained_at": "2026-04-26 14:30:00+00:00",
  "coins": 900
}

エラー

条件ステータス本文
gacha_id が無効400{"error": "gacha_id は整数で指定してください"}
未認証401{"error": "ログインが必要です"}
ガチャが存在しない404{"error": "そのガチャは存在しません"}
残コイン不足400{"error": "コインが足りません (必要 100 / 所持 50)"}

フロントが期待する shape (= 学習モードのチェック)

フロント (web/app.js) の中で、各 API について必須キーと型が 宣言されています。 サーバの応答が一致しなければ、UI は更新されず、デバッグコンソールが 期待と実際の差分を表示します。 

const SHAPE = {
  user:   { user: { id: "number", name: "string", display_name: "string", coins: "number" } },
  ok:     { ok: "boolean" },
  gachas: { gachas: [{ id: "number", name: "string", price: "number", pool_size: "number" }] },
  pull:   { gacha: "object",
            character: { id: "number", name: "string", rarity: "number", emoji: "string" },
            coins: "number" },
  box:    { user: "object", total_pulls: "number",
            items: [{ id: "number", name: "string", rarity: "number",
                      emoji: "string", count: "number" }] },
};

余分なキー (例: gachas 内の total_weight) は無視されます。 必須キーが揃っていれば OK。
