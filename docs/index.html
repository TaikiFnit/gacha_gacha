教材 所要時間: 完走で 8〜12 時間 動作環境: Google Colab (推奨) / ローカル

📘 gacha_gacha — バックエンドとデータベースを「自分の手」で覚える

この教材は、ガチャシステムを題材にして HTTP サーバー / SQL / Python を、Google Colab 上で 1 セルずつコードを動かしながら学ぶ連動ドキュメントです。 最終的にはブラウザでガチャを引ける Web アプリ一式が、教材通りに進めるだけで手元に組み上がります。

 最終形までコードを並べたリファレンスノートブック。 教材と並行で開けば比較しやすいですが、必須ではありません。

💡 学び方

各章は「📒 セル N」 という見出し付きのコードブロックで構成されています。 Colab に 新しいセルを追加 → 右上の Copy ボタンでコピー → 貼り付け → Shift+Enter を順に繰り返すだけで、章の最後まで進められます。

本教材の特徴は、各章が 「同じコードを書き足し / 書き換えて書き加えていく」 ステップ式の構成になっていること。ステップごとにサーバや DB が動く状態に保たれ、 1 ステップ進むたびに動作確認 → 次のステップで機能を 1 つ追加、を繰り返します。

慣れてきたら セルを書き換えて壊し、出力がどう変わるか を観察すると 吸収が深まります。

✅ 動作保証

本リポジトリの server/app.py は tests/test_e2e_sqlite.py で 27 ケースの E2E 検証を通っています。各章のコピペコード自体も、 書き起こした順に実行して期待出力が出ることを確認済みです。

本格的な PostgreSQL + Docker での確認は docker compose up -d 後 bash tests/smoke_curl.sh。

このシリーズで作るもの

ブラウザでガチャを引ける小さな Web アプリです。ユーザー登録できて、 コインを消費してガチャを引き、結果が Box (所持キャラ一覧) に蓄積されます。 フレームワーク (Django, Flask, FastAPI…) は意図的に使っていません。 HTTP がどう動き、SQL がどう発行されているか を観察しやすくするためです。
