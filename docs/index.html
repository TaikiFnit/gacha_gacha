教材 所要時間: 完走で 12〜18 時間

📘 gacha_gacha — バックエンドとデータベースを「自分の手」で覚える

この教材は、ガチャシステムを題材にして HTTP サーバー / PostgreSQL / Python を一気通貫で学ぶための連動ドキュメントです。 隣のディレクトリ ../server/ ../db/ ../web/ に置いてあるコードをそのまま読みながら進めます。

💡 学び方

各章は「読んで終わり」ではなく、自分で 1 ステップずつ書いて積み上げる 構成です。exercises/chXX/stepN_*.{py,sql} に各ステップの 「答え」が置いてあります。まずは見ずに課題を解き、 詰まったら答えを開いて差分を読み、動いたら宿題に進む、というループを回してください。

最終的に手元に積み上がったコードは、リポジトリ直下の server/ / db/ とほぼ同じ形になります。フルセット (= 答え) は いつでもそこから読めます。

✅ 動作保証 本リポジトリの server/app.py は tests/test_e2e_sqlite.py で 27 ケースの E2E 検証を通っています。手元で確認するには python tests/test_e2e_sqlite.py (Docker 不要) を実行してください。

このシリーズで作るもの

ブラウザでガチャを引ける小さな Web アプリです。ユーザー登録できて、 コインを消費してガチャを引き、結果が Box (所持キャラ一覧) に蓄積されます。 フレームワーク (Django, Flask, FastAPI…) は意図的に使っていません。 HTTP がどう動き、SQL がどう発行されているか を観察しやすくするためです。
