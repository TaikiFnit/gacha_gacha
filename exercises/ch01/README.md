# 第1章 ステップ式実習

進め方:
1. まずは何も見ずに「step1 を自分で書く」つもりで取り組む
2. 詰まったらこのフォルダ内の `stepN_*.py` を**答えとして**眺める
3. 自分のコードと差分を見比べて、何が抜けていたか言語化する
4. 動作確認してから次のステップへ

| step | やること                                | 入る道具              |
| ---- | --------------------------------------- | --------------------- |
| 1    | TCP socket だけで HTTP風の応答を返す     | `socket`              |
| 2    | `http.server` で最小の Hello GET         | `BaseHTTPRequestHandler` |
| 3    | パスで分岐 + クエリ受け取り              | `urllib.parse`        |
| 4    | POST で JSON を受け取る                  | `json`                |
| 5    | (method, path) ルーター辞書              | デコレータ            |
| 6    | 例外を JSON エラーに変換                 | `try/except`          |

step6 まで仕上がると、本物の `server/app.py` の足場が手の中で組めた状態になります。
そこに DB 呼び出し (第4章以降) を足していくのが第5章以降のゴールです。
